IMPORTANTE: SEM COBRANÇA
========================
Somente configure o Firebase no plano gratuito Spark, SEM Conta de faturamento/Blaze.
Firebase AI Logic com Gemini Developer API oferece uma modalidade gratuita limitada.
Quando a cota se esgotar, a geração poderá falhar, mas não significa que você deva pagar.
A integração está preparada, mas não pode ser usada até você criar seu próprio projeto Firebase Spark.
Não é possível garantir funcionalidade completa antes da configuração e teste reais no POCO F7.

CONFIGURAÇÃO (UMA VEZ, EM CADA NAVEGADOR/APARELHO)
=================================================
1. Abra https://console.firebase.google.com e crie projeto novo chamado, por exemplo, Meu Devocional Audio.
2. Mantenha projeto no plano Spark. NÃO clique em Adicionar faturamento, Blaze ou avaliação paga.
3. Registre aplicativo Web em Configurações do projeto > Geral > Seus apps > ícone </>.
   Utilize nome Meu Devocional. Não é necessário Firebase Hosting; o site continua no GitHub Pages.
4. Em AI Services > AI Logic, toque em Começar e selecione "Gemini Developer API".
   Não selecione Agent Platform Gemini API / Vertex, que requer faturamento.
5. Em Segurança > App Check, registre o app Web com reCAPTCHA Enterprise.
   No Google Cloud, crie uma CHAVE DE SITE Web de pontuação para o domínio d-oliveira97.github.io
   (não coloque https:// nem a rota /meu-devocional/).
   Não inclua localhost nas permissões de produção. Faça o registro e mantenha App Check ativo.
6. Abra o Meu Devocional 2.7, na seção "⚙ Configurar o Firebase gratuito / Charon".
   Preencha quatro campos da configuração pública:
   - Project ID (projectId do firebaseConfig)
   - App ID (appId do firebaseConfig)
   - Firebase Web API Key (apiKey do firebaseConfig; NÃO uma chave secreta Gemini)
   - Site key pública do reCAPTCHA Enterprise
   Confirme que o projeto está Spark sem faturamento e salve no aparelho.
7. Teste Dia 01 > "Ouvir estudo com Charon". O primeiro uso precisa de internet e
   poderá gerar vários trechos. Após o primeiro uso, os trechos ficam salvos localmente.

PROTEÇÃO
========
- Nunca cole chave privada Gemini nem credenciais da conta Google em código ou GitHub.
- Firebase Web config e site key são identificadores públicos próprios para clientes web;
  configure App Check e restrições de API, como explica a documentação Firebase.
- A proteção do App Check é fundamental em um app público, e não substitui regras de uso e cotas.
- O app estabelece limite local adicional de 12 solicitações por dia; esse controle local
  NÃO protege sozinho contra terceiros ou uso em outros dispositivos.
- O Gemini processa apenas o texto dos estudos e orações narrados; suas anotações NÃO são enviadas.
- O áudio será gerado com uma voz sintética; não é a voz literal de Deus.
- O modelo Gemini TTS e a configuração Firebase estão sujeitos a mudanças do Google.

PUBLICAÇÃO
==========
1. Antes de atualizar, faça backup das anotações na aba Progresso.
2. No GitHub, abra D-Oliveira97/meu-devocional > Add file > Upload files.
3. Envie os 15 arquivos DESCOMPACTADOS (não envie o ZIP) diretamente para a raiz.
4. Commit changes. Aguarde GitHub Pages publicar a versão.
5. Feche e reabra o app no Android com internet, sem limpar dados e sem reinstalar.
6. Configure a conexão Charon UMA VEZ no Android (o app instalado e o Chrome
   poderão ter armazenamento separado).
