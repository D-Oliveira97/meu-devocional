MEU DEVOCIONAL 2.9 — CHARON COM LEITURA ACOMPANHADA E PRÓXIMO DIA

NOVIDADES
1. Durante a narração da Charon, uma área "Acompanhar texto" destaca o parágrafo estimado do roteiro. A região pode ser recolhida. O realce também marca as seções correspondentes no texto normal do estudo quando disponíveis.
2. O tempo de cada trecho vem da duração real do WAV; a posição do texto é ESTIMADA pela proporção de caracteres em cada trecho, pois o Gemini não retorna timestamps por palavra. Não é uma transcrição sincronizada palavra por palavra.
3. Ao final do estudo/oração, aparece o botão "Ouvir o Dia seguinte com Charon". O usuário decide se quer começar o próximo estudo; nenhuma geração adicional é disparada automaticamente.
4. Modo de audiolivro contínuo e modo por partes continuam disponíveis. O destaque funciona nos dois.

IMPORTANTE
- O texto da ONBV permanece com seu leitor separado (sem narração neural).
- Os 365 estudos, suas anotações, progresso, lembretes e configuração Firebase Spark mantêm as mesmas chaves de armazenamento.
- Nenhuma solicitação extra à IA é feita apenas para destacar o texto. Tocar para ouvir o próximo dia pode consumir cota gratuita do Gemini.
- O acompanhamento visual funciona quando a tela está acesa; a reprodução de áudio já validada com tela apagada não depende desse destaque.
- Se o áudio de um trecho incluir pausas diferentes da média, o destaque pode adiantar ou atrasar um pouco. Não confundir com texto exato da Bíblia.
- Não desinstale nem limpe os dados do aplicativo para atualizar.

MEU DEVOCIONAL 2.8 — CHARON CONTÍNUA, SEM BENÍCIO

Nova opção: REPRODUÇÃO CONTÍNUA (AUDIOBOOK), marcada por padrão no painel Charon. O aplicativo prepara todos os trechos existentes (usando o cache de voz do aparelho) e une a fala em um único WAV. Não abre nova API nem gera áudio extra para unir: as chamadas à IA continuam sendo feitas por trecho conforme a versão anterior.

Vantagem: reprodução em uma só faixa, sem intervalos de troca de trecho; a tela pode ficar apagada onde o navegador permita.
Atenção: é preciso esperar o preparo da faixa completa no primeiro uso; a geração pode atingir a cota gratuita. Quem preferir começar imediatamente pode DESMARCAR reprodução contínua e usar o modo antigo.

Os trechos ficam salvos no IndexedDB do aparelho. O WAV unido é gerado temporariamente ao tocar, evitando duplicar o armazenamento. A ONBV continua separada, sem narração neural. Mantidos os 365 estudos, as anotações, os favoritos, os lembretes e a leitura local. A amostra Benício foi retirada.

PARA PUBLICAR NO GITHUB PAGES:
1. Faça backup das anotações antes de atualizar.
2. Descompacte o ZIP. Envie os 13 arquivos para a raiz do repositório GitHub em Add file > Upload files. Confirme Commit changes.
3. Depois de publicado, abra o app conectado à internet e atualize; feche e reabra se o Service Worker mantiver a versão anterior.
4. No Dia 01, em Ouvir com Charon, deixe marcada a opção Reprodução contínua e toque Ouvir estudo com Charon.
5. Não desinstale, não apague os dados locais e não acrescente chaves privadas ao GitHub. O projeto Spark não tem garantia de cota ilimitada.

LIMITAÇÃO: as vozes e pausas internas são determinadas pelo modelo; reunir o áudio elimina os intervalos entre requisições, mas não pode corrigir divergências de entonação nas fronteiras entre trechos. Para estudar sem a espera inicial, prefira o modo por partes.

IMPORTANTE: SEM COBRANÇA
========================
Somente configure o Firebase no plano gratuito Spark, SEM Conta de faturamento/Blaze.
Firebase AI Logic com Gemini Developer API oferece uma modalidade gratuita limitada.
Quando a cota se esgotar, a geração poderá falhar, mas não significa que você deva pagar.
A integração está preparada, mas não pode ser usada até você criar seu próprio projeto Firebase Spark.
Não é possível garantir funcionalidade completa antes da configuração e teste reais no POCO F7.

CONFIGURAÇÃO (UMA VEZ, EM CADA NAVEGADOR/APARELHO)
=================================================
1. Abra https://console.firebase.google.com e crie projeto novo chamado, por exemplo, Meu Devocional Audio.
2. Mantenha projeto no plano Spark. NÃO clique em Adicionar faturamento, Blaze ou avaliação paga.
3. Registre aplicativo Web em Configurações do projeto > Geral > Seus apps > ícone </>.
   Utilize nome Meu Devocional. Não é necessário Firebase Hosting; o site continua no GitHub Pages.
4. Em AI Services > AI Logic, toque em Começar e selecione "Gemini Developer API".
   Não selecione Agent Platform Gemini API / Vertex, que requer faturamento.
5. Em Segurança > App Check, registre o app Web com reCAPTCHA Enterprise.
   No Google Cloud, crie uma CHAVE DE SITE Web de pontuação para o domínio d-oliveira97.github.io
   (não coloque https:// nem a rota /meu-devocional/).
   Não inclua localhost nas permissões de produção. Faça o registro e mantenha App Check ativo.
6. Abra o Meu Devocional 2.7, na seção "⚙ Configurar o Firebase gratuito / Charon".
   Preencha quatro campos da configuração pública:
   - Project ID (projectId do firebaseConfig)
   - App ID (appId do firebaseConfig)
   - Firebase Web API Key (apiKey do firebaseConfig; NÃO uma chave secreta Gemini)
   - Site key pública do reCAPTCHA Enterprise
   Confirme que o projeto está Spark sem faturamento e salve no aparelho.
7. Teste Dia 01 > "Ouvir estudo com Charon". O primeiro uso precisa de internet e
   poderá gerar vários trechos. Após o primeiro uso, os trechos ficam salvos localmente.
